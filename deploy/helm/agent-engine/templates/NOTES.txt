PREREQUISITES (install these in the cluster BEFORE agents will reconcile):
  The controller integrates with cluster add-ons that provide CRDs it watches
  and creates. If they are absent you will see "no matches for kind ..." /
  CRD-not-found errors on the agent CRDs — the platform installs, but agents
  won't come up. Install:
    - Knative Serving   — the agent runtime (Service; scale-to-zero data plane).
    - Knative Eventing  — the event mesh (Broker/Trigger for event-driven agents).
    - KEDA              — event/metric autoscaling (ScaledObject).
  agent-engine deploys its own controllers + gateway + (optional) dev data plane
  and UI, but it does NOT bundle Knative or KEDA — install them separately
  (their upstream Helm charts / release YAMLs) on the target cluster.
